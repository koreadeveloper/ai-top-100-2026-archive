# 재사용 스킬

[← 메인 README](../README.md)

`interview-agent-sprint`는 인터뷰·문서·업무 API·실제 채널·평가를 함께 다루는 시간제한 에이전트 대회용 작업 지침이다. 당시 문제의 해답을 넣은 봇이 아니라, 다음 프로젝트에 적용할 방법론이다.

[SKILL.md](interview-agent-sprint/SKILL.md)를 읽거나 해당 폴더를 자신의 Codex skills 디렉터리에 복사해 `$interview-agent-sprint`로 호출한다. 실제 규정·마감·도구 권한은 새로 확인해야 한다.

필수 흐름은 일찍 연결하기, 출처와 범위 대조, 공통 원장, 실패 기반 조사, 실제 실행 검증, 제출 동결이다. 구조 검증은 통과했으나 독립 에이전트가 새로운 대회를 완주하는 행동 검증을 끝냈다고 주장하지 않는다.
